# أَثَر — ديوان صلاح الدين الخزاعي

موقعُ صفحةٍ واحدة (Single Page) باللغة العربية لعرض القصائد، بتنسيقٍ راقٍ للبيت الشعري (صدر وعجز)،
ودعمٍ كامل للاتجاه من اليمين إلى اليسار (RTL)، ووضعٍ نهاري/ليلي، وتصميمٍ متجاوب مع الهواتف.

لا يحتاج الموقع إلى أي بناء (No build step): ملفات HTML/CSS/JS ثابتة + ملف بيانات واحد.

---

## 1) هيكل المشروع

```
athar-site/
├── index.html              ← الصفحة الوحيدة
├── data/
│   └── poems.json          ← ★ مصدر البيانات الوحيد (القصائد + التصنيفات + معلومات الموقع)
├── assets/
│   ├── css/style.css       ← كل التنسيقات (الثيمات + الاستجابة + الطباعة)
│   ├── js/app.js           ← منطق العرض والبحث والتصنيفات والمحرّر
│   └── img/cover.jpg       ← صورة واجهة الموقع (استبدلها بصورتك)
├── vercel.json             ← إعدادات نشر Vercel
├── netlify.toml            ← إعدادات نشر Netlify
├── sync_inline.py          ← يحدّث النسخة المضمّنة الاحتياطية داخل index.html
└── README-ar.md            ← هذا الملف
```

> **النسخة المضمّنة الاحتياطية:** داخل `index.html` وسم `<script id="fallbackData">` يحمل نسخة من
> البيانات تُستخدم فقط إذا منع المتصفح جلب الملف (فتح `index.html` مباشرة). على أي خادم/منصة نشر
> يُقرأ `data/poems.json` أولاً وتُتجاهل النسخة المضمّنة. بعد تعديل `data/poems.json` نفّذ:
> `python3 sync_inline.py` لتحديثها (اختياري).

## 2) تشغيل محلي (اختياري)

```bash
cd athar-site
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

> ملاحظة: لا تفتح `index.html` بالنقر المزدوج (file://) لأن المتصفح يمنع جلب `data/poems.json`؛
> استخدم خادماً محلياً كما أعلاه، أو انشر الموقع مباشرة.

## 3) إضافة قصيدة جديدة (طريقتان)

### الطريقة أ — من داخل الموقع (معاينة فورية)
1. افتح الموقع وانزل إلى التذييل واضغط **«محرّر البيانات»**.
2. عدّل الـ JSON (أضف قصيدة أو تصنيفاً…) ثم اضغط **«تطبيق وحفظ»**.
3. اضغط **«تنزيل poems.json»** واحفظ الملف منزّلاً فوق `data/poems.json` في مشروعك،
   ثم ارفعه إلى GitHub/Netlify/Vercel ليصبح التغيير دائماً للجميع.

### الطريقة ب — تحرير الملف مباشرة
افتح `data/poems.json` وأضف عنصراً إلى مصفوفة `poems`:

```json
{
  "id": "اسم-لاتيني-فريد",
  "title": "عنوان القصيدة",
  "category": "حنين",
  "date": "2026-01-15",
  "place": "",
  "epigraph": "إهداء أو استهلال اختياري",
  "tags": ["شوق", "ليل"],
  "featured": false,
  "verses": [
    { "sadr": "الشطر الأول (الصدر)", "ajoz": "الشطر الثاني (العجز)" },
    { "sadr": "…", "ajoz": "…" }
  ]
}
```

- `category` يجب أن يطابق `id` أحد التصنيفات في مصفوفة `categories`
  (وإن أضفت تصنيفاً جديداً في `category` دون تعريفه، سيُنشأ تلقائياً باسمه).
- الحقول الاختيارية: `place`, `epigraph`, `tags`, `featured`, `date`.
- الأبيات: كل بيت = `{ "sadr": الصدر, "ajoz": العجز }`.

### تغيير صورة الواجهة أو السيرة أو وسائل التواصل
كلها في قسم `site` من نفس الملف:
- `heroImage`: مسار الصورة (مثلاً `assets/img/cover.jpg`) — ضع صورتك في `assets/img/` وأشر إليها هنا.
- `bio`: مصفوفة فقرات السيرة. `bioImage`: صورة الشاعر (اختياري).
- `contact`: `email`, `whatsapp` (أرقام فقط), `facebook`, `instagram`, `x`, `youtube`.

## 4) النشر مجاناً

### GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `athar`) وارفع مجلد المشروع كاملاً إلى فرع `main`.
2. من `Settings → Pages`: اختر `Deploy from a branch` ثم الفرع `main` والمجلد `/ (root)`.
3. رابطك: `https://USERNAME.github.io/REPONAME/`

### Netlify (الأسرع — سحب وإفلات)
- **خيار فوري بلا حساب معقّد:** افتح https://app.netlify.com/drop واسحب مجلد `athar-site` (أو ملف ZIP منه)
  وستحصل على رابط مباشر خلال ثوانٍ.
- أو اربط مستودع GitHub: Netlify يكتشف `netlify.toml` تلقائياً (publish = جذر المشروع).

### Vercel
1. اربط مستودع GitHub من https://vercel.com/new
2. Framework: `Other` — لا يحتاج أمر بناء؛ `vercel.json` يضبط الترويسات والكاش.
3. انشر، وستحصل على رابط `*.vercel.app`.

> عند تحديث القصائد: عدّل `data/poems.json` وارفعه (push) وسيتحدّث الموقع مباشرة،
> لأن الملف مُعدّ بعدم التخزين المؤقت (no-cache) في إعدادات النشر.

## 5) ميزات مضمّنة

- تصنيف القصائد (chips) + بطاقات تصنيفات قابلة للنقر.
- بحث فوري في العناوين والأبيات مع تمييز النتائج، ومتسامح مع التشكيل والهمزات.
- ترتيب: الأحدث / الأقدم / أبجدياً / الأطول.
- حفظ القصائد المفضلة (نجمة) في متصفحك + قسم «المحفوظات».
- نسخ نص القصيدة أو رابطها المباشر (`#p-…`).
- وضع ليلي/نهاري، زر طباعة بتنسيقٍ نظيف، عودة للأعلى، وشريط تقدّم القراءة.
- محرّر بيانات مدمج مع تنزيل الملف المعدّل.

## 6) ملاحظات تقنية

- الخطوط: Amiri (العناوين والأبيات) + IBM Plex Sans Arabic (الواجهة) + Reem Kufi (الشعار)،
  مع بدائل نظامية إن تعذّر تحميل الخطوط.
- كل المسارات نسبية، لذا يعمل الموقع على أي مسار فرعي (مثل صفحات GitHub) دون تعديل.
